# TypDoc

Early prototype

More documentation to come soon.

The concept is to make it easier to share documents in typst with all the resources it needs for compilation while also providing a simple way for people to modify anything they want in that document to regenerate the PDFs. And also provide convenient GUI to modify simple variables set up in the typst template without having to understand the typst syntax. That allows typst users to share documents that other people can modify and use.

The GUI contains a simple interface to edit variables, add more alternatives the different values for the variables for batch export of different versions of the same document.
